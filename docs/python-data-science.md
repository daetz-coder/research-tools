# Python 数据科学环境

## 简介
Python 数据科学栈是科研数据分析的重要工具集。

## 核心组件
- **Anaconda**: 包管理环境
- **CUDA**: GPU加速计算
- **Jupyter Notebook**: 交互式编程
- **NumPy/Pandas**: 数据处理
- **Matplotlib/Seaborn**: 数据可视化

## 环境搭建
1. 安装 Anaconda
2. 配置 CUDA 环境
3. 安装必要包
4. 测试环境

## 常用包
- **数据处理**: pandas, numpy
- **可视化**: matplotlib, seaborn, plotly
- **机器学习**: scikit-learn, tensorflow
- **深度学习**: pytorch, keras

## 使用技巧
- 使用虚拟环境
- 合理配置 GPU
- 掌握常用函数
