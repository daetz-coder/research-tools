# Git 版本控制指南

## 简介
Git 是分布式版本控制系统，广泛用于代码管理。

## 主要功能
- 版本控制
- 分支管理
- 协作开发
- 代码备份

## 常用平台
- **GitHub**: 代码托管
- **GitLab**: 企业级平台
- **Gitee**: 国内平台

## 快速开始
1. 安装 Git
2. 配置用户信息
3. 创建仓库
4. 基本操作

## 常用命令
```bash
git init          # 初始化仓库
git add .         # 添加文件
git commit -m ""  # 提交更改
git push          # 推送代码
```

## 使用技巧
- 使用 .gitignore
- 合理使用分支
- 编写清晰的提交信息
