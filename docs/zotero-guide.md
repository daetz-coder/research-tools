# Zotero 使用指南

## 简介
Zotero 是一款免费的文献管理工具，支持文献收集、整理、引用和协作。

## 主要功能
- 文献收集与整理
- 自动引用格式
- 笔记与标签管理
- 团队协作

## 推荐插件
- **Translate for Zotero**: 自动翻译文献
- **Zotero PDF Translate**: PDF内翻译
- **Zotero Better BibTeX**: 更好的引用格式

## 快速开始
1. 下载安装 Zotero
2. 注册账户
3. 安装浏览器插件
4. 开始收集文献

## 使用技巧
- 使用标签分类文献
- 利用笔记功能记录想法
- 设置自动备份
