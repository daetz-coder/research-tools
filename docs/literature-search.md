# 文献检索策略

## 主要平台
- **Google Scholar**: https://scholar.google.com/
- **ArXiv**: https://arxiv.org
- **PubMed**: 生物医学文献
- **IEEE Xplore**: 工程技术文献

## 检索技巧
- 使用关键词组合
- 利用高级搜索
- 设置时间范围
- 关注引用关系

## 工具推荐
- **OneScholar CRX**: 快速查询期刊分区
- **LetPub**: SCI期刊影响因子查询
- **Sci-Hub**: 文献下载（注意版权）

## 管理工具
- **Zotero**: 文献管理
- **Mendeley**: 文献整理
- **EndNote**: 引用管理

## 使用技巧
- 建立个人文献库
- 使用标签分类
- 定期备份数据
- 关注最新研究
