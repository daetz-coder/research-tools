# Clash 使用指南

## 简介
Clash 是网络代理工具，支持多种协议。

## 主要功能
- 网络代理
- 规则配置
- 流量统计
- 多平台支持

## 平台支持
- **Windows**: Clash for Windows
- **Linux**: Clash GUI Linux
- **macOS**: ClashX

## 快速开始
1. 下载对应版本
2. 配置订阅地址
3. 启动服务
4. 设置系统代理

## 订阅地址
- 推荐: https://gw-yd.com/
- 其他平台可自行搜索

## 使用技巧
- 合理选择节点
- 配置规则文件
- 监控流量使用
- 定期更新订阅
